## 🏗️ Technical Architecture (30 seconds)

- **Backend**: FastAPI + 4 ML Models (Isolation Forest, XGBoost, Random Forest, NLP)
- **Blockchain**: 5 Solidity Smart Contracts (Token, Insurance, DID, Threat Intel, DAO)
- **Real-time**: WebSocket/Socket.IO for live updates
- **3D**: Three.js + React Three Fiber for immersive visualization
